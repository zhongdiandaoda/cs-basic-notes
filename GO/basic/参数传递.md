形参：函数括号内定义的参数

实参：调用时传递的参数

值类型：数组，struct，string

引用类型：map，channel，指针

slice是一个结构体，包含len，cap和指向底层数组的指针

# 基本类型变量作为参数

使用普通变量作为函数参数的时候，在传递参数时对变量值进行拷贝，将实参的值复制给形参，当函数对形参进行处理时，并不会影响原来实参的值。

```
func main() {
	a, b := 0, 1
	swap(a, b)
	fmt.Println(a, " ", b) //0 1
}
func swap(a, b int) {
	a, b = b, a
}
```

# 指针作为参数

将实参指针的值拷贝给形参，形参和实参指向内存中相同的地址

# 数组作为参数

在Go语言中，数组作为参数与基本类型变量作为参数的处理方式相同

demo：

```
func main() {
	a := [3]int{1, 2, 3}
	inc(a)
	fmt.Println(a)  //[1 2 3]
}
func inc(a [3]int) {
	for i, _ := range a {
		a[i]++
	}
}
```

# Slice作为参数

切片是一个引用类型，作为参数时，形参会拷贝slice的底层数组的内存地址。

```

func main() {
	a := []int{1, 2, 3}
	inc(a)
	fmt.Println(a) //[2 3 4]
}
func inc(a []int) {
	for i, _ := range a {
		a[i]++
	}
}
```

在函数中通过append对形参进行修改后，实参对应的Slice保持不变

```

func main() {
	a := make([]int, 9, 10)
	b := a[:3]
	inc(a)
	fmt.Println(a) //
	fmt.Println(b)
}
func inc(x []int) {
    //a的size为9，cap为10，不需要扩容，将a的底层数组最后一个元素设置为10
    //返回值形参x包含10个元素，而a包含9个元素，底层数组有修改，切片引用无修改
	x = append(x, 10) 
	a[0] = 100 //修改a的底层数组第一个元素为0
}

// a: [100 0 0 0 0 0 0 0 0]
// b: [100 0 0]
```
